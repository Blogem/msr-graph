- [ ] 6.3 Implement the provenance writer (two-activity pattern, mirroring `cmd/loader/nist.go`): type the stable `msrd:activity-mine a prov:Activity ; prov:wasAssociatedWith agent:mine@<version>` once in `urn:msr:data` (no timestamps, idempotent), and append to `urn:msr:provenance` via `INSERT DATA { GRAPH <urn:msr:provenance> { … } }` a per-run `urn:msr:run:mine/<ts>` activity node (agent, start/end timestamps, `owl:versionInfo`) plus one `prov:wasGeneratedBy` generation edge per asserted fact; stamp each written `msr:ChangeProposal` resource with `prov:wasGeneratedBy` that run node. The PROV edges on auto-accepted individuals are what satisfy the landed SHACL `CatalogIndividualProvenanceShape` — a missing edge makes the SHACL-enabled repo reject the `INSERT DATA` atomically, surfaced as a loud HTTP error by the reused Python `sparql.SparqlClient` (`raise_for_status`); treat such a rejection as a provenance bug to fix, not a routine path
